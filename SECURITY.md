# Politica de securitate / Security policy

## Română

Acest depozit conține sursa site-ului [dedede.ro](https://dedede.ro): pagini statice generate cu Astro și un singur script PHP, `public/sideform.php`, care primește formularul de contact.

### Cum raportezi o vulnerabilitate

Te rog să **nu** deschizi un issue public. Folosește raportarea privată din GitHub: tabul **Security** al depozitului, apoi **Report a vulnerability**. Mesajul ajunge doar la proprietarul depozitului.

Ajută mult dacă incluzi:

- ce ai găsit și unde (adresa paginii sau fișierul și linia);
- pașii prin care se poate reproduce;
- ce ar putea face un atacator cu ea.

Te rog să nu trimiți formularul de contact în mod repetat și să nu încerci să accesezi date ale altor persoane în timp ce verifici o problemă.

### La ce să te aștepți

Primești un răspuns în cel mult 7 zile. Dacă problema se confirmă, este reparată cât de repede se poate, iar tu ești menționat în descrierea reparației, dacă dorești.

### Ce versiuni sunt acoperite

Doar ramura `main`, care este cea publicată pe dedede.ro. Ramurile și versiunile vechi (cele pe Elder.js) nu mai sunt întreținute.

## English

This repository holds the source of [dedede.ro](https://dedede.ro): static pages built with Astro and one PHP script, `public/sideform.php`, which receives the contact form.

### Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private reporting: the repository's **Security** tab, then **Report a vulnerability**. The report is visible only to the repository owner.

It helps to include what you found and where, the steps to reproduce it, and what an attacker could do with it. Please do not submit the contact form repeatedly or try to reach other people's data while checking an issue.

### What to expect

You get a reply within 7 days. Confirmed issues are fixed as soon as possible, and you are credited in the fix if you wish.

### Supported versions

Only the `main` branch, which is what dedede.ro serves. Older branches and the Elder.js versions are no longer maintained.
